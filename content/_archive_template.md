# 핵심 질문  
> 외부 관측자 기준으로 사건지평선 도달은 실제로 완료되는가?

# 최초 직관  
- 시간 지연이 무한대로 증가한다  
- 따라서 영원히 도달하지 못할 것 같다  
- 그런데 낙하자는 유한 시간 내 통과한다고 한다  
- 이 둘이 동시에 참이라는 것이 직관적으로 충돌함
# 사고 흐름  
  
# 직관 충돌 지점  

### 충돌 A — "본다"와 "존재한다"의 혼동  
  
- 관측 불가능성과 사건 발생 자체를 동일시함  
- 적색편이와 실제 운동 정지를 혼동  
  
### 충돌 B — 좌표 시간 vs 고유시간  
  
- 서로 다른 시간 체계를 동일한 물리량처럼 취급함
